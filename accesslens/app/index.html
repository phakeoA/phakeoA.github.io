Open an Access database in your browser

This page opens .mdb and .accdb files in this tab. The file is read by code running in your browser and is never uploaded: none of the page's code sends data anywhere (every build is checked for it), its security policy blocks outbound connections from the page, and you can watch the Network tab of the developer tools to confirm nothing leaves.

Browsing, searching and exporting a table to CSV are free. For one-click access from the toolbar, get the extension for Chrome or Firefox, or read more on the AccessLens home page.
