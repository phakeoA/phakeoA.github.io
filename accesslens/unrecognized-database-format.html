“Unrecognized database format” — what it means and how to fix it

You double-click an .accdb or .mdb file and Access answers Unrecognized database format 'C:\…\file.accdb' (error 3343). The file is almost never “not a database”. It is a database written in a dialect of the format that your copy of Access does not read.

The four usual causes

  1. An .accdb opened in Access 2003 or older. The .accdb format arrived with Access 2007. Anything earlier cannot read it at all, whatever the error says.
  2. A newer data type inside the file. A database that uses the Large Number type (Access 2016 build 16.0.7812 and later) or Date/Time Extended (2020 and later) is refused by every earlier version with exactly this message, even though both are “.accdb”.
  3. A damaged file. A copy interrupted mid-write, a network drop while the database was open, or a full disk. Access reads the header, finds it inconsistent, and reports the same error.
  4. Not an Access file. A renamed export, a backup container, or the .laccdb/.ldb lock file that sits beside a database while it is open. Check the file size: a lock file is a few hundred bytes.

Fixes, in the order worth trying

  1. Match the version. Open the file on a machine with a current Microsoft 365 Access. If it opens there, the file is fine and your copy is simply older than the file.
  2. Compact & Repair a copy. Copy the file first. In Access, open a blank database, then Database Tools → Compact and Repair Database and pick the copy. This rebuilds the structure and rescues most interrupted-write damage.
  3. Restore a backup. If Compact & Repair also fails, the file is genuinely damaged; a backup from before the incident is the only complete fix.
  4. Just read the data. If the goal is the records rather than the application, you do not need a compatible Access at all. Questions

Can I open an .accdb in Access 2003?

No. Access 2003 predates the .accdb format. Either open the file in Access 2007 or later, or read it with a viewer that parses the format directly, such as AccessLens.

Does "Unrecognized database format" mean my file is corrupt?

Usually not. Most cases are a version mismatch: the file uses a newer format or data type than the installed Access. Corruption is the third most common cause, after that and opening an .accdb in a pre-2007 Access.
