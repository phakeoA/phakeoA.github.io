Privacy Policy

AccessLens (Chrome extension) · Last updated 30 August 2026

AccessLens collects nothing. No personal data, no usage data, no analytics, no crash reports, no identifiers. There is no server to collect it with.

What the extension does with your files

When you open a .mdb or .accdb file, it is read and parsed entirely inside your own browser tab, on your own machine. The file is never uploaded, copied off your device, or transmitted in any form. When you close the tab, nothing about it is retained.

Why this is verifiable rather than a promise

AccessLens declares no permissions in its manifest — no network permission, no host permissions, no storage, no content scripts, no external connectivity of any kind. The extension therefore has no technical means of transmitting data, independent of any assurance given here.

  • The permissions list on its Chrome Web Store listing is empty.
  • Its release build is checked automatically for network APIs and remote code; the check fails the build if any are present.
  • The extension behaves identically with your network connection disabled.

Passwords

If you open an encrypted database, you are prompted for its password. That password is used in memory to decrypt the file locally and is never stored, cached, or transmitted.

Third parties

There are none. No analytics provider, no error-reporting service, no advertising network, no content delivery network. This website loads no third-party scripts, fonts or trackers either.

Data sharing and sale

No data is collected, so none is sold, shared, transferred, or used for any purpose — including advertising, credit assessment, lending, or any purpose unrelated to the extension's single function of viewing Access database files you explicitly open.

Children

The extension collects no data from anyone, including children.

Changes

If a future version ever needed a permission, that change would be disclosed on the Chrome Web Store listing before it could be installed, and this page would be updated with the date above.

Contact

Questions about this policy can be sent to the developer email listed on the Chrome Web Store listing.
