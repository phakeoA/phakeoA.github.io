Open an Access database on a locked-down work computer — no admin rights, no install

The common situation: a vendor, a colleague or an old system hands you an .accdb or .mdb. Access is not on the machine, IT will not install it, the free Access Runtime also needs an installer you cannot run, and the data is confidential enough that pasting it into a web converter is not an option either.

Why the usual answers fail here

  • Microsoft Access / Access Runtime — both need an installer and local admin rights.
  • Portable desktop viewers — most corporate policies block unsigned executables outright, admin or not.
  • Online converters — the file leaves the company. For client, HR, financial or health data that is a policy breach, not a shortcut.
  • Excel's "Get Data from Access" — works, but only if the Access Database Engine is installed, which it often is not on a machine without Access.

What does work: a permission-less browser extension

Chrome and Edge extensions install into your browser profile, not the machine, so they normally need no administrator. AccessLens opens .mdb and .accdb files (Access 97 to 2019, including password-protected ones) in a browser tab, lets you browse and search every table, and exports to CSV for Excel.

It is built for exactly this environment: it requests no permissions at all — no network, no host access, no storage, no content scripts. It has no technical means of sending the file anywhere, and the empty permissions list on its store page is something you can show IT.

If the organisation blocks the Chrome Web Store, an administrator can allow this one extension by its ID, ceilhkpcnofeomaibeldikllpgjolaml, through the browser's extension policy.

Questions

Can I open an .accdb file without installing Microsoft Access?

Yes. A browser extension that parses the Access format, such as AccessLens for Chrome and Edge, opens the file in a tab without any installer or administrator rights.

Is it safe to open confidential Access files this way?

AccessLens requests no network permission, so the file is processed inside the browser tab and cannot be transmitted. You can confirm the empty permissions list on the store listing or use it with the network disconnected.
