Extension blocked by your administrator: getting AccessLens approved at work

You found a way to read the .accdb file without Access, clicked Add to Chrome, and got Blocked by your administrator, or a Request button instead. Your company decides which extensions its browsers may install. This page is what to send, and what IT needs to check.

If you see a Request button

Some companies let you ask for an extension from the store page. Click Request and give this reason:

I need to read a Microsoft Access (.accdb / .mdb) file without installing Access. AccessLens (ID ceilhkpcnofeomaibeldikllpgjolaml) requests no permissions and has no network access; the file is processed inside the browser tab, so nothing leaves this computer.

The request goes straight to your IT administrator's console. Approving it changes nothing else about your browser.

If there is no Request button

Send the same reason to your IT team by email or ticket, with the extension ID ceilhkpcnofeomaibeldikllpgjolaml and a link to this page. Admins can allow a single extension by its ID without opening the whole store.

For IT administrators: what to check

  • Permissions: none. No host permissions, no content scripts, no storage or tabs permission. The permissions list on the store page is empty.
  • Network: none. The file is parsed inside the extension's own tab by a Web Worker. The release build is checked automatically and fails if any network API is present, and the extension behaves the same with the network disconnected.
  • Data: nothing collected — no analytics, no telemetry, no account. If someone activates the optional Pro licence, the key is checked offline and kept in the browser; it is never sent anywhere. See the privacy policy.
  • Read-only. It never modifies the database file.
  • Allowing it: in the Google Admin console, add the ID under Chrome apps and extensions, or list it in the ExtensionInstallAllowlist policy, which both Chrome and Microsoft Edge support.

Licensing at work

AccessLens is free, including at work. The optional Pro features cover large databases: exporting the whole database at once and searching every table, when a database has more than 20 tables or 50,000 rows in total. Below those limits everything is free, and exporting one table to CSV is free at any size. Using Pro for work requires the Business licence: $15, one-time, covering the people who use Pro at one organisation. Invoices can carry the company name and VAT number. Full terms are on the licence page.

Questions

Why is a Chrome extension blocked by my administrator?

Your organisation manages Chrome and only allows approved extensions. An administrator can approve one extension by its ID without changing anything else.

Does AccessLens need any permissions?

No. It declares no permissions, no host access and no content scripts, and it has no network access, so the database file never leaves the computer.

Is AccessLens free for business use?

Yes. The free features are free for everyone, including at work. Only the optional Pro features need a paid licence: exporting the whole database at once and searching every table, on databases with more than 20 tables or 50,000 rows in total. Using Pro for work requires the Business licence ($15, one-time).
