PROJECTS

01
AI Pokémon Showdown Battler
GITHUB ↗

Game-playing AI that learned competitive Pokémon from roughly 86,000 human matches - the full ML pipeline, data collection through evaluation. A custom game-state encoder feeds an attention-based neural network in PyTorch, with a second model that drafts the team pre-match. Sharpened with self-play reinforcement learning (PPO) and probabilistic reasoning over hidden information, then stress-tested against adversarial opponents. Plays live ranked matches on its own via browser automation (Playwright / WebSockets): 51% win rate over ~1,000 games, peaking four wins short of the top 500 in its format. Backed by a 215-file pytest suite running in CI (GitHub Actions).

AI Assistant

Conversational AI assistant in Python integrating an open-source LLM with a Discord interface. Speech-to-text (Whisper), long-term memory via a vector database with semantic retrieval, retrieval-augmented generation (RAG), and automated web scraping, with GPU-accelerated inference (CUDA).

03
Home Network Server

Self-hosted network infrastructure on a headless Linux Raspberry Pi: household DNS and DHCP for every connected device (Pi-hole + Unbound) plus a password-protected SMB shared drive. Reachable from anywhere via WireGuard VPN with self-updating dynamic DNS, and Wake-on-LAN power control of a desktop PC over SSH. Managed through a mobile web control panel (Python / Flask, systemd) with live status, one-tap wake/sleep, and automated backups.
